# Design: Reorganize Research Repository

## Technical Approach

Mechanical change; the design's value is ordering, atomicity and verifiability. Five ordered
slices: rename-only, reference repair, `.gitignore`, article import, test import. Every slice
is independently revertible and has a machine-checkable gate.

## Architecture Decisions

### Decision 1 — `git mv` first, reference repair second

**Choice**: all 13 `git mv` operations land in slice 1, with zero content edits. References are
repaired in slice 2.
**Alternatives**: repair references first; interleave per-file.
**Rationale**: three reasons, strongest last.
1. After the move, a grep for a stale token is *by construction* the complete repair worklist
   with a known target of zero. Before the move, the same grep returns real files and stale
   references indistinguishably.
2. References-first produces an intermediate state where a typo and a correct-but-early edit
   look identical; nothing can localize the mistake until the move lands.
3. `integration_cycle/README.md` is fully rewritten. If the rename and the rewrite share a
   commit, git's rename similarity falls below threshold and records delete+add, destroying the
   file's history. Rename-only first is the only way to keep it.

### Decision 2 — five commits, not one

`auto-chain`, 400-line budget. Measured volume:

| Slice | Content | Changed lines | Note |
|---|---|---|---|
| 1 | 13 `git mv`, no edits | **0** | pure renames; `--numstat` reports `0 0` |
| 2 | 11 reference lines, 2 READMEs, `_nbcheck.py` | ~210 | authored; under budget |
| 3 | `.gitignore` rewrite only | ~30 | highest risk, smallest diff — reviewed alone |
| 4 | `git add main/` (13 files) | ~1611 + 4 PNGs | pre-existing article source, import only |
| 5 | `git add tests/` (2 files) | 228 | pre-existing, already green |

Slices 3 and 4 are deliberately split: slice 3 carries all the risk and none of the volume,
slice 4 all the volume and none of the risk. Slices 4 and 5 are scope-of-tracking imports of
already-authored content, not authored change — flag them `size:exception` with that reason
rather than sub-splitting a LaTeX article.

### Decision 3 — hand edits, never scripted `sed`

**Choice**: exact-string edits per site.
**Alternatives**: `sed -i` over a token list.
**Rationale**: a repo-wide `sed` would rewrite `.ipynb` cell source (forbidden) and
`openspec/*.md` (which records the old paths deliberately, as history). Only 11 lines are
affected. **Rule: never edit a file that is itself in the move map before its `git mv`** — edit
the two archived `.md` files at their new path in slice 2.

### Decision 4 — `.gitignore`: delete `main/`, ignore byproducts by extension

Empirically confirmed (coordinator, `git check-ignore` in a throwaway repo): with the bare
`main/` line present, **every `!` negation is inert** — git never descends into an excluded
directory, so `main/main.tex`, `main/report/results.tex` and `main/report/topo_phases.png` all
stay ignored and `git status` looks clean while the change does nothing. The `main/` line MUST
be deleted, not commented or narrowed. `papers/` is a deliberate directory exclusion and stays.

`main/report/toy.txt` was inspected during design: a hand-authored ASCII lattice, not a
compiler byproduct. **It is source — version it.** This closes the proposal's open item.

Exact replacement for the region at lines 53-60 of `.gitignore`:

```gitignore
# ── Output figures (regenerated by notebooks) ────────────────────────────────

# ── LaTeX article (main/) ─────────────────────────────────────────────────────

# a bare `main/` or `main/report/` rule excludes the directory, git never descends
# into an excluded directory, and every `!` rule below would become inert — the
```

Rejected: `main/**/*.aux` (more compact, but unmeasured here and the tree is only two levels
deep).

### Decision 5 — `_nbcheck.py` discovers, and empty discovery is fatal

**Choice**: resolve the base directory from `__file__`, walk it, treat `argv` as optional
substring filters, exit 2 on an empty result. Findings stay informational (exit 0).
**Rationale**: `__file__` removes the cwd assumption the current version carries. Coupling
findings to exit status would import the notebooks' unmeasured pre-existing warnings into this
change's gate — recorded as a follow-up instead. `NB[:2]` must also go: after renumbering, `01`
names both a training and an evaluation notebook.

Exact new head and tail for `notebooks/integration/_nbcheck.py`; `collect()` is unchanged.

```python
import json, ast, builtins, sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent

# ... collect() unchanged ...

def discover(filters):
    nbs = sorted(p for p in ROOT.rglob('*.ipynb')
                 if '.ipynb_checkpoints' not in p.parts)
    if filters:
        nbs = [p for p in nbs
               if any(f in p.relative_to(ROOT).as_posix() for f in filters)]
    return nbs

notebooks = discover(sys.argv[1:])
if not notebooks:
    print(f'_nbcheck: FATAL: no notebooks found under {ROOT}'
          f'{" matching " + repr(sys.argv[1:]) if len(sys.argv) > 1 else ""}',
          file=sys.stderr)
    sys.exit(2)
print(f'_nbcheck: {len(notebooks)} notebook(s) under {ROOT}')

for path in notebooks:
    label = path.relative_to(ROOT).as_posix()
    nb = json.loads(path.read_text(encoding='utf-8'))
    # ... body unchanged, but replace the final print(f'{NB[:2]}:') with:
    print(f'{label}:')
```

## Testing Strategy

Run from the repo root. Report each as `<command>: <observed result>`.

| # | Command | Expected |
|---|---|---|
| 1 | `git diff --cached -M --numstat -- '*.ipynb'` | every row `0\t0\t<old> => <new>`; 12 rows (4 archive + 8 integration) |
| 2 | cell-source hash multiset, pre vs post (below) | identical |
| 3 | `rg -n 'integration_cycle/' --glob '!openspec/**' --glob '!AGENT_PROMPT*.md' --glob '!*.ipynb'` | no match (exit 1) |
| 4 | same for `notebooks/replaced/` | no match |
| 5 | same for `notebooks/cycle/ciclo_completo.md` | no match |
| 6 | same for `notebooks/cycle/ciclo_external.md` | no match |
| 7 | same for `04a_\|04b_\|04c_\|04d_` | no match |
| 8 | `.venv/bin/python -m pytest tests/ -q` | `14 passed` |
| 9 | `.venv/bin/python notebooks/integration/_nbcheck.py` | prints `_nbcheck: 8 notebook(s)`; exit 0 |
| 10 | `.venv/bin/python notebooks/integration/_nbcheck.py __nope__; echo $?` | `2` |
| 11 | `git check-ignore -v <trackable>` for the 13 `main/` source paths | exit 1 each (not ignored) |
| 12 | `git check-ignore -v <byproduct>` for `main/main.{pdf,log,aux,bbl,blg,fls,fdb_latexmk,spl,out}`, `main/report/{results,topology}.{pdf,aux,log,out}`, `main/report/b.log` | exit 0 each (ignored) |
| 13 | `git check-ignore -v papers/` | exit 0 — still ignored |
| 14 | `git ls-files main/ \| wc -l` | `13` |
| 15 | `git ls-files tests/` | exactly `tests/conftest.py`, `tests/test_topology.py` |
| 16 | `git status --porcelain` | no tracked-file change left over; untracked set unchanged from the pre-change baseline (`01_baseline_simulation.ipynb`, `.codegraph/`, `openspec/`) |

Checks 11 and 12 are both mandatory: a rule that ignores everything and a rule that ignores
nothing both leave `git status` looking clean.

Check 2, the cell-source hash proof — run before slice 1 and after slice 2:

```bash
git ls-files -z 'notebooks/integration/*.ipynb' 'integration_cycle/*.ipynb' \
| xargs -0 -I{} .venv/bin/python -c \
  "import json,hashlib,sys; nb=json.load(open(sys.argv[1],encoding='utf-8')); \
   print(hashlib.sha256(''.join(''.join(c['source']) for c in nb['cells']).encode()).hexdigest())" {} \
| sort > /tmp/nbhash.after
diff /tmp/nbhash.before /tmp/nbhash.after
```

Names are deliberately excluded from the hash so the multiset compares across the rename.

## Threat Matrix

N/A — no routing, shell-argument, subprocess, VCS/PR-automation, executable-classification or
process-integration boundary. `_nbcheck.py` reads JSON and `ast`-parses it; it never executes
notebook source.

## Migration / Rollout

No migration. Rollback is `git revert` over the five-commit range, or `git checkout main -- .`
before merge. No data, checkpoint or Kaggle state is mutated.
